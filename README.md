# Smriti Mandhana – HTML Profile Page

Welcome to the **Smriti Mandhana HTML Project**, a beginner-friendly web development project created using plain HTML. This project serves as a great starting point for anyone learning how to build and structure a basic web page. It showcases a tribute page dedicated to one of India’s most celebrated women cricketers, **Smriti Mandhana**.


## About the Project

This project is a simple and informative profile page that highlights Smriti Mandhana's achievements, contributions to Indian women's cricket, and provides links for viewers to explore more about her career. It demonstrates essential HTML elements and teaches how to organize content semantically and visually.



## Key Features

* HTML Boilerplate Setup
  Implements proper document structure using `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>` tags.

* Text Content
  Uses heading tags (`<h1>`, `<h2>`, etc.) and paragraph tags (`<p>`) to organize content effectively.

* Embedded Media
  Includes a YouTube video embedded using the `<iframe>` tag.

* Navigation Links
  Uses anchor tags (`<a>`) to link to external resources such as Wikipedia and YouTube.

* Page Structure
  Applies horizontal rules (`<hr>`) and centering for layout (note: `<center>` is deprecated in modern HTML but included here for learning purposes).



## Learning Outcomes

By reviewing or building this project, you will learn:

* How to structure a basic HTML document
* How to present text using headings and paragraphs
* How to embed multimedia using `<iframe>`
* How to link to external resources
* How to create a clean and readable layout with standard HTML elements



## Project File

* `index.html` – The main HTML file containing all content and structure for the Smriti Mandhana profile page



## How to Use

Open the `index.html` file in any web browser to view the page. You can also host it using platforms like GitHub Pages or Netlify to share it publicly.
